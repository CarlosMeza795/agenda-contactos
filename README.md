# Agenda de Contactos

Aplicación de consola para gestionar contactos, desarrollada en Python.

## Funcionalidades

- Agregar contactos
- Buscar contactos por nombre
- Eliminar contactos
- Listar todos los contactos en tabla

## Tecnologías

- Python 3
- SQLite
- Rich (interfaz de consola)

## Cómo ejecutar

1. Clonar el repositorio
2. Crear entorno virtual: `python -m venv venv`
3. Activar entorno virtual: `venv\Scripts\activate`
4. Instalar dependencias: `pip install rich`
5. Ejecutar: `python agenda.py`
